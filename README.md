# LLL-редукция базиса и применение к криптоанализу


Реализация алгоритмов редукции базиса целочисленных решёток:

* метод Гаусса
* алгоритм LLL
* проверка LLL-приведённости
* атака на ранцевую систему Меркля–Хеллмана
* атака на конгруэнтную схему

## Описание

### Метод Гаусса (`gauss.py`)

Редукция базиса двумерной решётки. На каждом шаге векторы меняются местами, если второй короче первого. Затем из второго вектора вычитается первое, умноженное на целый коэффициент — отношение скалярного произведения к квадрату длины первого, округлённое до ближайшего. Процесс идёт, пока коэффициент не станет нулевым. Итоговый базис удовлетворяет условию: модуль коэффициента не превосходит 0.5.

---

### Алгоритм LLL (`lll.py`)

Обобщение метода Гаусса на случай произвольного числа векторов. На каждом шаге вектор `b_k` уменьшается относительно всех предыдущих — из него вычитаются целые кратные `b_j`, чтобы проекции были маленькими (не больше 0.5 по модулю). Затем проверяется условие Ловаса: если оно нарушено, `b_k` и `b_{k-1}` меняются местами, и алгоритм откатывается назад. Параметр `delta` (обычно 0.75) управляет строгостью проверки.

---

### Конгруэнтная схема (`attack_congruential.py`)

Ищется решение сравнения `a*x = b (mod m)` при условии, что `|x|` не превосходит корня из `m`. Строится решётка из трёх векторов, где третий столбец масштабируется на `t = floor(sqrt(m))`. LLL находит короткий вектор, вторая координата которого и есть искомый `x`.

---

### Меркль–Хеллман (`attack_merkle_hellman.py`)

Публичный ключ: `pub[i] = (r * priv[i]) mod q`. Шифротекст: сумма `msg[i] * pub[i]`. Строится базис размерности `n+1`, где последний столбец — открытый ключ, а последняя строка — минус шифротекст. После LLL в базисе появляется короткий вектор из `{-1, 0, 1}`, координаты которого (по модулю) дают исходное сообщение.

---

## Проверка (`checks.py`)

Функция `is_lll_reduced(basis, delta=0.75)` проверяет два свойства приведённого базиса:

* все внедиагональные коэффициенты разложения не превосходят 0.5 по модулю
* выполняется условие Ловаса с заданным параметром `delta`

## Запуск

В `main.py` выставить константу:

```python
TASK = "GAUSS"
TASK = "LLL"
TASK = "CONGRUENTIAL"
TASK = "KNAPSACK"
```

Затем:

```bash
python main.py
```
